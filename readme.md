# Catálogo de Podcasts

Projeto desenvolvido para a disciplina de Desenvolvimento Mobile.

## Funcionalidades

- Login com usuário e senha
- Cadastro de episódios
- Lista de episódios
- Reprodução de áudio via streaming
- Play/Pause
- Exclusão de episódios

## Como executar

Abra o projeto no Android Studio e execute em um emulador ou dispositivo Android com acesso à internet.
